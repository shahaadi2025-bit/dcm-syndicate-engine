ML LAYER

Train on your book. Serve anywhere. No GPU cathedral.

Ridge demand regression + logistic tighten classifier, trained online or straight from any CSV you hand it. JSON artifacts, deterministic seeds, feature-set hashing.

  • 📊 CSV → deployed model in one command
    Point it at your archived deal book with any column names; median-impute, min-max scale, one-hot, train, ship.
  • 🎯 Confidence blending
    Model weight grows with sample count against a transparent desk heuristic. No silent model supremacy.
  • 🧪 12 dedicated tests
    Feature vector schema, artifact round-trips, hash stability, missing-column failures — all pinned.
